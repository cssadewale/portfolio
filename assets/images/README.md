# Profile Photo Instructions

## How to add your photo to this portfolio

### Option 1: Upload to this folder (RECOMMENDED)
1. Name your photo file one of the following:
   - `profile.jpg`  ← preferred
   - `profile.jpeg`
   - `profile.png`
   - `profile.webp`
2. Place it in this folder: `assets/images/`
3. Push to GitHub — the site will automatically detect and display it.
4. No code changes needed.

### Photo requirements
- Minimum size: 300×300 pixels (square is best)
- Maximum file size: 500KB (compress at tinypng.com if needed)
- Format: JPG or PNG preferred
- Background: Any — but a clean/solid background looks most professional

### Option 2: Use the in-site photo modal
- Open the live website
- Click the small ✏️ pencil icon on the profile photo
- Either paste a direct image URL or a Google Drive share link
- The photo is saved in your browser's localStorage

### Option 3: Google Drive link
1. Upload your photo to Google Drive
2. Right-click → Share → "Anyone with the link" → Copy link
3. Paste the link in the photo modal on the site
4. The site automatically converts it to a direct display URL

---
**Note:** Option 1 (uploading to the repo) is the most reliable
because it works for ALL visitors, not just you. Options 2 and 3
use browser localStorage which is device-specific.
